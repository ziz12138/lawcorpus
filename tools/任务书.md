# 任务书：中文法学论文框架语料库（我自己执行）

> 这份是我给自己定的执行规范。文件一到，照这份干，不临时改主意。

## 0. 输入

用户会发来的 PDF，**按年划分**（2024 / 2025 / 2026），每个 PDF 是一年的合集，可能含一个或多个刊（中国法学 / 中外法学 / 法学研究 等），也可能一刊一期一个文件。以实际文件为准，先看结构再定切分方案。

只处理可搜索 PDF（有文字层）。不用联网、不抓知网、不装付费工具。

## 1. 切分顺序（从大到小）

1. **年**：一个 PDF = 一年（或按文件名判断）。
2. **刊**：在一年的合集里找刊边界。信号：新刊的封面 / 目次页 / 刊名大字。找不到就按「目录页 + 该刊固定页眉」切。
3. **期**：按目录页或卷期页眉（如「2025 年第 3 期」）切。
4. **篇**：每篇起始页有「题名 + 作者 + 摘要 + 关键词」，正文随后。

每切一层都校验数量：**切出的篇数 = 该期目录页列出的篇数**。对不上就停下报告「哪一期差几篇」，不硬凑。

## 2. 输出目录（本仓库）

```
law-framework-corpus/
├── corpus/
│   ├── articles.jsonl     一篇一行
│   ├── terms.jsonl        术语层
│   ├── phrases.jsonl      用语层
│   ├── chains.jsonl       逻辑链模板
│   ├── titles.jsonl       标题句式
│   └── SCHEMA.md          字段说明
├── SKILL.md
├── scripts/
│   ├── build_corpus.py    从 PDF 重建全库（可重跑）
│   └── query.py           检索并输出 3–5 张框架卡
└── demo/                  3 篇样例（供他人自测）
```

**通用性**：脚本不写死本机绝对路径；语料目录按 `LAWCORPUS_DIR` 环境变量 → 脚本同级 `corpus/` → 报错提示，三级回落。`SKILL.md` 里不出现本机用户名。

## 3. 数据规范（字段）

### articles.jsonl（一行一篇，UTF-8 无 BOM）

```json
{
  "id": "sha1(题名|年份) 前 12 位",
  "journal": "中国法学", "year": 2025, "issue": 3,
  "column": "专题研讨：数据法",
  "title": "数据可携权的规范构造",
  "authors": ["张三"],
  "abstract": "原文照抄",
  "keywords": ["数据可携权", "个人信息保护"],
  "pages": "5-24", "startPage": 5,
  "discipline": "民法|刑法|公法|法理|知识产权|数据法|其他",
  "outline": [{"level":1,"label":"一、","title":"问题的提出"}],
  "outlineCount": 5,
  "source": "pdf:2025.pdf",
  "extractedAt": "ISO8601"
}
```

`discipline` 是标签，不做题库切分（通用库，检索时不强制过滤）。

### terms.jsonl
```json
{"term":"请求权基础","kind":"概念|制度|方法|评价标准","freq":42,
 "journals":["中国法学","中外法学"],"coTerms":["构成要件","抗辩"],
 "examples":[{"text":"原句","ref":"中国法学2025(3)〈题名〉"}]}
```
来源：关键词 + 摘要正文名词短语（2–8 字，去虚词/人名/刊名）。只留 `freq>=3` 或跨 2 刊。

### phrases.jsonl
```json
{"phrase":"本文认为","type":"功能套语|连接推进|评价动词",
 "freq":88,"position":"摘要中段|转折处|收尾",
 "examples":[{"text":"原句","ref":"..."}]}
```
词表起点：功能套语（本文认为/有鉴于此/质言之/值得强调的是/从教义学上看/规范目的/体系解释）、
连接推进（进而言之/反之/据此/就此而言/不无疑问/殊值探讨）、评价动词（肯认/指摘/检讨/厘清/证成/消解/涵摄/误置/溢出）。

### chains.jsonl（逻辑链，最值钱）
```json
{"chain":"教义学型","steps":["问题提出","规范梳理","构成要件拆解","适用边界","结语"],
 "count":37,"samples":["中国法学2025(3)〈题名〉"],
 "abstractFlow":["背景","问题","命题","方法","结论"]}
```
证据 = 摘要功能句序列 + 目录章节层级。模板：教义学型/实证型/比较法型/案例评析型/立法论型。
**每个模板必须在库里找到 ≥2 篇支撑，否则不写。**

### titles.jsonl
```json
{"pattern":"主副标题（破折号）","freq":61,"samples":["..."]}
```
主副标题/冒号限定/从X到Y/设问式/之字结构/比较法式/制度规则式/概念界定式/陈述式。

## 4. 抽取规则（最容易做错）

1. **摘要**：「摘要/内容摘要/【摘要】」到「关键词」之间整段，原文照抄。抽不到写 `null`，**绝不生成或补全**。
2. **关键词**：以「关键词」开头那行，按 `； ; ， , 、` 切分，去句号。
3. **目录**：
   - 一级 `一、` / `第一章`；二级 `（一）` / `1.1`；三级 `1.`（排除脚注编号：页底、字号小、带 ①）
   - 无编号「引言」「问题的提出」也认：独立成行、≤30 字、不以句号结尾、下一行是成段正文
   - 遇「参考文献」即停
   - 去页眉页脚、刊名页码行、作者简介、基金项目、中图分类号、收稿日期
   - <2 条记 `null`
4. **双栏串行**：中文期刊双栏，直接 pdftotext 会左右交替串行。优先按 x 坐标切栏再拼；做不到就后处理救标题行。抽样 10 篇，串行率 >10% 停下报告。

## 5. 质量门槛

- 抽样 10 篇（跨刊跨年）逐字段人工核对，出「抽错清单」
- 报告：总篇数、按刊、按年、摘要/关键词/目录完整率、串行疑似数、discipline 分布
- 随机抽一期目录页与库内篇名逐条对，缺的解释原因
- 任一完整率 <90%，先修逻辑再交付

## 6. SKILL.md 要点

frontmatter `name: law-paper-writing`，description 塞满触发语（法学论文/写论文/摘要/关键词/投稿/选题/框架/审稿/润色/CLSCI/法学期刊/教义学）。

四条主流程（优先级）：①写论文（选题→3–5 张框架卡→结构模板→章节骨架→术语校准）②润色（比对偏离，不代写）③审稿自查（检查清单）④教学/申报（统计+例证）。

硬约束写最前面：每次只取 3–5 张框架卡；每条结论带出处；目录是规则骨架不代表质量、摘要照抄非工具观点；只给框架与术语校准，**正文用户自己写**；只存题录层不存全文。

结尾自检：术语是否堆砌、有无 AI 味连接词、结构是否对上模板、是否带出处。

## 7. 工作顺序

**第一期验证**：只处理一期（默认《中国法学》2025 年第 1 期，或用户指定），交回：
切出几篇 + 3 篇完整记录（含 outline）+ 抽错清单。用户确认后再批量。

批量阶段：每处理完一个 PDF 报进度和该文件完整率。
